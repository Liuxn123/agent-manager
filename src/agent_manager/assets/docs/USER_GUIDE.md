# Agent 管家使用说明

适用版本：v0.3.1。可以按左边的模块直接阅读，不必一次看完。

## 1. 先看这里

这个工具帮你保存 Hermes、工作 Agent、项目和笔记的本地资料，并在需要时恢复。管家可以独立打开，不需要先启动 Hermes。

**日常用法：打开工作台 → 检查状态 → 选择需要保护的资料 → 立即备份。**

**换电脑用法：带走程序和备份 → 在新电脑打开管家 → 恢复到新文件夹 → 核对原应用的路径和登录。**

第一次试用，建议先选一个小项目备份，再做一次“恢复演练”。这会在临时目录里真实恢复文件，原项目不变。

| 你想做什么 | 去哪里 |
| --- | --- |
| 看整体情况 | 工作台 |
| 保存或恢复本机 Hermes | 本地 Hermes |
| 检查服务器、保存远端 Hermes | 服务器 Hermes |
| 保存代码、知识库、Obsidian 笔记 | 项目与 Obsidian |
| 保存 Codex、WorkBuddy 等的项目和本地记录 | 其他 Agent |
| 找备份、试恢复、换电脑 | 备份与迁移 |
| 看操作是否成功、为什么失败 | 活动记录 |
| 改保存位置、管理备份口令 | 设置 |

几个词的意思：**登记**是告诉管家文件在哪里；**备份**是保存当时的一份副本；**校验**是检查副本完整性；**恢复演练**是试着还原副本；**恢复**才会把资料实际放回目标目录。

## 2. 工作台

**用来做什么：** 一眼看见登记了哪些资料、有没有备份、最近的检查结果。

1. 点击“检查全部状态”，等待后台任务结束。
2. 在“资料保护”列表查看名称、最近备份、保护状态和连接情况。
3. 双击一项资料，进入对应模块。

“备份 Hermes”针对登记的第一项本地 Hermes。“搜索本地记录”用于找旧资料；Hermes 当前搜索会话标题，其他 Agent 搜索支持的本地文本记录。“换电脑恢复”进入备份页。

| 状态 | 你需要做什么 |
| --- | --- |
| 未备份 | 先创建一份备份 |
| 待校验 | 在对应模块重新校验 |
| 已校验 | 备份通过完整性检查 |
| 已演练 | 这份项目或 Agent 备份真实试恢复过 |
| 已过期 | 超过 48 小时未创建新副本；有变化就再备份，旧副本仍可恢复 |
| 目录需重选 | 编辑资料，选择这台电脑上的位置 |
| 状态后有“历史” | 这是过去的结果，点击检查状态刷新 |

最近 7 天图表统计的是**管家执行的操作**，不代表 Agent 的工作进度、Token 或费用。发现进程运行也不代表它正在处理某个任务。

## 3. 本地 Hermes

**用来做什么：** 使用现有 Hermes 备份工具，保护会话、技能、记忆、配置及其恢复材料。

日常只需选中已登记的 Hermes，然后点“检查状态”或“立即备份”。检查后，右边“概览”显示会话、消息、技能和记忆数量；详细结果放在“配置与诊断”。

需要新增或修正时点“添加”或“编辑”：

| 字段 | 怎么理解 |
| --- | --- |
| Hermes 运行目录 | Hermes 保存配置和资料的目录，不是管家程序目录 |
| Hermes 备份仓库 | 已有 Hermes 备份脚本和快照所在的仓库 |
| 工具 Python | 可以运行这套 Hermes 备份脚本的 Python |
| 受保护口令文件 | 已有加密备份口令文件的位置，只选文件，不填写内容 |
| Workspace | 可选，帮助登记其中的项目 |
| 启动程序和参数 | 可选，仅在需要从管家启动时填写 |
| 提交并推送 Git | 勾选后沿用原工具的远端推送配置；需要网络和已有 Git 登录 |

**恢复步骤：** “更多操作 → 校验备份” → 退出 Hermes → 点击“恢复…” → 看预览 → 核对目标并确认。

本地 Hermes 的完整恢复可能把当前资料回到快照时的状态，包含替换会话；当前独有会话可能被移除。先保存现在的资料，再恢复旧版本。它不是“恢复演练”。

Hermes 原生快照保存在自己的备份仓库里，**不会出现在 `.amb` 备份列表**。需要恢复时回到本页。

## 4. 服务器 Hermes

**用来做什么：** 按需连接 Linux 服务器，检查网关、磁盘、内存和备份环境，创建或校验远端备份。

日常：选中服务器 → “检查状态” → 看右侧概览。连接成功、网关正常、备份环境就绪是不同的检查项；连接成功不代表已有可恢复备份。

设置只需在服务器变化时修改：

| 字段 | 怎么理解 |
| --- | --- |
| SSH 别名 / user@host、端口 | 连接到哪台服务器，默认端口 22 |
| SSH 登录账号 | 登录服务器的用户名；只有别名已配置用户名时才可留空 |
| 私钥文件 | 这台电脑已有的 SSH 私钥位置，不是备份口令 |
| SSH 配置、主机指纹文件 | 可沿用已有 config、known_hosts，确认连接的是正确服务器 |
| 远端 Hermes、备份仓库、知识库 | 服务器上的目录，不填写本机盘符 |
| 远端 Python、备份运行账号 | 服务器执行备份工具的环境和账号 |
| 网关服务名、服务范围 | 已有 systemd 网关的名称及系统/用户服务类型 |
| 远端口令文件 | 服务器已有的加密备份口令文件位置 |

“读取已有服务器连接参数”会填入已有环境中的公开连接参数，保存前仍需核对。登录账号漏填可能导致用本机用户名连接而失败。

**备份：** “检查状态”成功后点“立即备份”。**校验：** “更多操作 → 校验备份”。“更多操作”还提供已支持的网关启动、停止、重启和备份提交查看。

**恢复：** 校验 → “恢复…” → 指定服务器上的新目录或空目录 → 看预览 → 确认。数据恢复后还需要检查运行环境、知识库位置和服务配置，再决定启用新网关；当前程序不替你完成生产环境切换。

服务器校验通过只说明快照文件完整，不能当作加密凭据已经解密验证。管家不会把远端备份自动下载成 `.amb`，也不会自动把本机 SSH 私钥复制到 U 盘。

## 5. 项目与 Obsidian

**用来做什么：** 保存代码、未提交的工作文件、笔记及附件。

1. 点“添加”，选择项目或 Obsidian 类型。
2. 填一个好认的名称，选择要备份的整个文件夹。Obsidian 选择笔记库根目录。
3. “额外排除目录名”可以先留空；需要跳过大体积生成目录时再填写。
4. 保存登记，选中资料，点“立即备份”，设置备份口令。
5. 完成后查看提示的 `.amb` 文件位置。

普通项目和 Agent 资料备份不需要再配置 Python。备份前让编辑器、Obsidian 或其他程序停止写入资料。

**常用操作：** “更多操作 → 打开目录”；Obsidian 还可以“在 Obsidian 打开”。新电脑要安装 Obsidian 才能使用这个按钮。

建议备份完成后点“更多操作 → 试一次恢复（临时目录）”，或在备份页点“恢复演练”。演练通过会显示“已演练”。

恢复文件会放入新目录或空目录，原项目不会被覆盖。Git 本地历史会另存为恢复目录中的历史文件；当前程序不会自动拼接 `.git` 和工作文件。需要恢复 Git 历史时，再按 README 中的步骤处理。

## 6. 其他 Agent

**用来做什么：** 保存 Codex、WorkBuddy、CodeBuddy、Claude Code 等的项目成果，以及机器上实际存在的聊天、配置和附件。

1. 点“添加工作 Agent”，选你使用的 Agent。
2. 如果还想保存项目成果，选择“项目文件夹”；只保存记录时可以不填。
3. 点“自动找记录目录”，核对找到的文件夹；找不到时点“添加目录”。可以登记多个。
4. 保存，点“检查状态”，确认目录存在。
5. 退出对应 Agent 或停止其写入，然后点“立即备份”。

选择项后，右侧概览列出会备份哪些资料，先核对范围，避免把同一大目录重复登记。

“浏览本地记录”可以查看支持的文本、Markdown、JSON 和 JSONL；“更多操作 → 搜索本地记录”可输入关键词搜索。数据库会备份，但不是每一种数据库都能直接在管家里阅读。

Agent 的 SQLite 数据库使用一致性快照；不同数据库之间没有联合快照保证，其他文件仍需停止写入。备份不会自动下载原应用仅存于云端的聊天。

换电脑后先通过管家恢复文件，再在原应用核对目录、版本和登录。**文件恢复成功不等于原应用可以直接续聊。** 有些会话依赖云端账号或原来的路径，需要从原应用导入或重新登录。

可选的“从管家启动 Agent”适用于配置好的非交互进程；交互式终端工具继续在终端运行即可。停止按钮只控制本次管家启动的进程，不会关闭你自己打开的 Codex 等应用。

## 7. 备份与迁移

**用来做什么：** 集中查看项目、Obsidian 和其他 Agent 的 `.amb` 备份。

`.amb` 是管家生成的加密备份文件。它携带文件及恢复登记信息，需要创建时的备份口令。列表中的名称、时间、文件数、大小和校验状态帮助你选对版本。

**试一次恢复：** 选一份备份 → “恢复演练” → 输入备份口令。管家恢复到临时目录并逐个比对文件，通过后清理临时目录。原项目不变，不会给原应用切换资料。

**正式恢复或换电脑：**

1. 点“恢复选中备份…”；外来的备份点“从备份文件恢复”。
2. 选择 `.amb`，输入创建它时的备份口令。
3. 选一个新的“恢复总文件夹”。多目录备份可以调整项目文件、记录等子文件夹名称。
4. 点“查看恢复清单”，确认名称、文件数、范围和目标。
5. 勾选确认，点“执行恢复”。非空目标会被拒绝。
6. 完成后资料会重新登记，在对应模块可以查看和打开。

换电脑不需要先导入资源配置，仅有 `.amb` 和正确口令也能恢复。恢复完成后请核对原应用的项目路径。

“已校验”和“已演练”是针对那一份副本的结果。备份较旧时，应根据后来有没有修改资料决定是否重新备份。

## 8. 活动记录

**用来做什么：** 判断你点的操作做完没有，找到失败原因。

选中一条任务，下方看结果和脱敏日志。状态“已完成”表示该操作结束；例如“检查状态”完成，不代表已经创建了备份。

“请求取消选中任务”会在安全检查点停止，关键恢复写入期间可能需要等待。网络中断时先检查服务器实际结果再重试，避免把“没有收到结果”当作“远端肯定没执行”。

旧的失败记录会保留，后续成功不会删除旧记录。工作台的“待检查”可能因此包含之前的失败，结合时间和最新任务判断。

搜索和浏览得到的聊天内容不写入管家任务历史。

## 9. 设置

设置页的常用内容只有下面几项，“更多设置”默认折叠。

| 选项 | 建议怎么用 |
| --- | --- |
| 备份保存位置 | 便携版默认 `backups`，通常保持默认；修改后点“保存设置” |
| 每项自动备份保留 | 默认 10 份。自动备份成功且校验通过后，清理该项资料可确认的旧 `.amb` 版本，包含之前手动创建的版本 |
| 备份口令库 | 可选，用一个主口令保护保存的各项备份口令 |
| 更多设置 | 配置导入导出、环境检查、口令移除和管家数据目录 |

修改备份保存位置**不会搬走已有备份**。旧备份仍留在原目录，必要时用“从备份文件恢复”选择它。

**口令库怎么用：** 第一次点“创建口令库”，输入并确认至少 8 个字符的主口令。之后每次打开管家需要“解锁口令库”；关闭管家后重新锁定。备份弹窗里勾选保存口令时，需要先解锁。你也可以一直临时输入口令，不创建口令库。

| 名称 | 用途 |
| --- | --- |
| 备份口令 | 解锁一项资料的 `.amb`，恢复时必须用原口令 |
| 口令库主口令 | 解锁保存备份口令的小保险箱，不直接替代 `.amb` 的口令 |
| SSH 私钥 / Hermes 口令文件 | 沿用 Hermes 和服务器已有的连接、加密材料 |

这几种凭据请分清，并独立保存备份口令和主口令。忘记备份口令无法解密旧副本；忘记主口令不能取出库里存的口令。

**开启自动备份：** 在某项资料“编辑”中勾选自动备份。需要有可用的已保存口令；便携模式需要解锁口令库。管家打开期间约每天执行一次，发现对应 Agent 运行时延后。服务器当前采用手动备份。

“导出资源配置”保存的是登记名称和路径，不是资料备份，不包含聊天、项目文件或密钥。导入只合并新登记项；新电脑仍需核对路径。

## 10. U 盘与换电脑

Windows 便携版，把**整个 `AgentManager-Portable` 文件夹**复制到 U 盘，不要只复制 exe。

| 内容 | 作用 |
| --- | --- |
| `AgentManager.exe`、`_internal` | 程序及运行组件 |
| `portable.json` | 告诉程序在自身目录保存数据 |
| `data` | 你的登记配置、活动记录和可选加密口令库 |
| `backups` | 管家创建的 `.amb` 备份 |
| `restored` | 如果使用默认恢复位置，放恢复出来的资料 |

复制前关闭管家，完成后再安全拔出 U 盘。程序内部路径会跟随目录位置和盘符变化；原来位于电脑硬盘的项目、Obsidian、Hermes、SSH 文件不会自动随程序带走。

在另一台 Windows 电脑上：打开管家 → 需要时解锁口令库 → 恢复资料 → 编辑登记路径 → 检查状态。若备份保存位置改到了程序外，也需要单独带走对应备份。

macOS 或 Linux 要使用对应系统的包。Windows exe 不能直接在它们上运行，但 `.amb` 备份格式可跨平台恢复；路径和原应用需要重新配置。Hermes 原生备份需要另外携带或取得对应备份仓库，不能只带 `backups` 文件夹。

更新程序前关闭管家、留一份完整目录副本；替换运行组件时保留原 `data`、`backups` 和恢复资料。

## 11. 常见问题

**添加了资料，为什么还显示未备份？** 登记只记录位置，请再点“立即备份”。

**为什么查到 Agent 在运行，却不知道它在做什么？** 当前检测的是进程，不是任务内容。要知道等待输入或正在处理什么，需要原应用提供任务事件，当前没有接入。

**为什么有些聊天搜不到？** 记录可能不在登记目录、仅在云端，或格式还不支持。当前搜索每次最多读取 300 个文件、32 MiB，并限制结果数量；Hermes 目前搜索会话标题。

**为什么恢复说目标非空？** 请选择新文件夹，先恢复并检查，之后再由你决定如何放回原应用。

**换电脑后服务器连接失败？** 核对 SSH 登录账号、私钥位置、配置及可信主机指纹。U 盘里的配置不会携带原电脑的 SSH 私钥。

**为什么自动备份没有运行？** 确认已为该项开启、管家正打开、口令已保存且口令库已解锁；对应 Agent 运行时会延后。查看活动记录可核对实际执行情况。

**旧 Hermes Workbench 可以移除吗？** 管家独立运行，已迁入状态、资料保护、诊断和活动汇总。旧 Workbench 的实时对话、模型配置与上下文统计暂未迁入；如果你还用这些功能，可以先保留它。
