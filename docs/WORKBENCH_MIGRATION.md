# Workbench 迁移到 Agent 管家

新版独立运行，不加载 Hermes Desktop SDK、Workbench 插件或其后端。

| 原 Workbench 功能 | 新版入口 |
|---|---|
| 节点与备份状态摘要 | 工作台：资料保护、最近备份、校验与演练状态 |
| SSH 只读检测、网关和主机资源 | 服务器 Hermes：检查状态、概览与配置诊断 |
| 服务器环境变量连接参数 | 编辑服务器：读取已有连接参数；新增明确登录账号和指纹文件 |
| 会话、记忆、技能数量 | 本地 Hermes：快照概览，注明快照时间 |
| 活动统计与七天趋势 | 工作台：管家自身完成的任务统计，区分于 Hermes 会话任务 |
| 知识库、Workspace 的仓库入口 | 项目与 Obsidian：登记、目录预览、打开和备份；仅明确启用的独立知识库管理 Git |
| 原生备份和推送入口 | Hermes 页面：调用原生工具并校验；沿用显式推送设置 |

Desktop SDK 独有的实时会话用量、当前模型与上下文占用暂不迁移，独立程序无法可靠读取同一份实时状态。缺失状态显示尚未检测；记录显示检测时间，不把历史缓存当实时。

旧 Workbench 的代码、插件登记和数据保持原样，方便对照。完成日常试用后，可在 Hermes 的插件设置中移除 Workbench；不删除 Hermes 的 Workspace、备份仓库或知识库。Agent 管家不依赖旧插件，移除插件不会影响新的管理入口。

为保持精简，没有迁移任意命令执行器、完整技能编辑器、Docker 或复杂编排；后续能力继续通过已有 AdapterRegistry 增加。
