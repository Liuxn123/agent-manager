# Workbench 迁移到 Agent 管家

下表使用 v0.7.0 入口名称。管家默认首页为“今日”，备份与技术诊断集中在“数据安全”；不再展示七天任务趋势。

新版独立运行，不加载 Hermes Desktop SDK、Workbench 插件或其后端。

| 原 Workbench 功能 | 新版入口 |
|---|---|
| 节点与备份状态摘要 | 今日：简要最近备份与异常；数据安全：保护概览、校验与演练状态 |
| SSH 只读检测、网关和主机资源 | 数据安全 → 备份与恢复 → 服务器 Hermes：检查状态、概览与配置诊断 |
| 服务器环境变量连接参数 | Agent → 编辑登记：沿用连接参数、登录账号和指纹文件 |
| 会话、记忆、技能数量 | 数据安全 → 本地 Hermes：快照概览，注明快照时间 |
| 活动统计与七天趋势 | 趋势已弱化移除；数据安全 → 操作记录保留任务结果 |
| 知识库、Workspace 的仓库入口 | 项目：规范项目、归档与 Obsidian 共用文件；备份登记在数据安全管理 |
| 原生备份和推送入口 | 数据安全 → Hermes：调用原生工具并校验；沿用显式推送设置 |

Desktop SDK 独有的实时会话用量、当前模型与上下文占用暂不迁移，独立程序无法可靠读取同一份实时状态。缺失状态显示尚未检测；记录显示检测时间，不把历史缓存当实时。

旧 Workbench 的代码、插件登记和数据保持原样，方便对照。完成日常试用后，可在 Hermes 的插件设置中移除 Workbench；不删除 Hermes 的 Workspace、备份仓库或知识库。Agent 管家不依赖旧插件，移除插件不会影响新的管理入口。

为保持精简，没有迁移任意命令执行器、完整技能编辑器、Docker 或复杂编排；后续能力继续通过已有 AdapterRegistry 增加。
