# Agent 管家 v0.7.3

修复日常入口与空项目体验，不改备份格式或项目真源。

- 本机模式未配置工作区时明确引导；源码 start.cmd 优先沿用相邻已安装便携版数据，显式数据环境变量仍优先。
- 新项目创建后清除旧搜索并选中新项目。
- 项目单份文档缺失时保留其他文档与笔记，显示具体问题并禁用依赖该文档的操作。
- 项目 / Agent 进入资源库重置遗留筛选；新资源自动填入当前项目 / Agent，显示全部资源可清除所有筛选；保存后自动选中新资源。
- Agent 备注保存后进入资源库查看同一份 Markdown；更改资料位置后不会写回旧位置。
- 未登记、未选中或没有来源时正确禁用按钮；系统打不开入口 / 目录时显示原因，不记录成功使用。
- 旧 STATUS 阶段短句和“阻塞/待决定”兼容显示；不改原文。

验证结果见 VALIDATION.md。服务器恢复与个人项目归档不作为真人试用的写入对象。

## v0.7.2

项目界面改为项目卡片与选中项目工作区，压缩重复顶栏，围绕阶段、下一步与记录组织信息。

- 当前状态呈现目标、进展、阶段总结、行动、风险和最近记录；保留一键切换原文。
- 清单任务统计来自已有复选框 / 任务表格，不计算虚构项目百分比，不展开外部任务链接。
- 阶段总结摘要引用实际完成、验证与下一阶段计划；完整八栏目仍在总结标签和 HANDOFF。
- 常用操作移到项目标题旁；目录、文档编辑、阶段关联、归档和 Obsidian 索引整理进更多操作。
- 大窗口三栏概览，小窗口可滚动、按钮换行，避免长文字和操作被压缩。
- 沿用后台读、编辑冲突保护、Obsidian 文件监听、归档确认及旧数据格式。

本机最终回归 114 项，112 项通过、2 项符号链接权限限制跳过。实际窗口验证了菜单、任务、阶段总结、关联资源及写入日志；个人项目只读查看。Windows / Linux / macOS ARM / macOS Intel 四项 CI 的测试、打包和便携目录移动检查均成功。

## v0.7.1

今日体验优化：参考卡片式工作台，将任务、重点、时间轴、项目、最近工作与保护状态分层展示。蓝色导航与紧凑卡片减少大面积空白；小窗口保留任务 / 项目双栏，长说明省略并提供完整工具提示。

- 直接添加任务 / 日程，可填写优先级与时间，仍写入同一份每日 Markdown；整体编辑入口保留。
- 完成率来自真实任务；高优先级只统计未完成项；今日重点按优先级 / 时间选择最多三项，完成后自动更新。
- 项目卡片使用已有阶段与下一步；不推算项目百分比。最近工作沿用真实进入记录，备份卡片显示已记录的结果并定位同一登记。
- 手动专注计时支持开始 / 暂停，关闭结束，不采集 Agent 活动。
- 延续原文件锁、编辑冲突保护、Obsidian 刷新、备份格式和便携机制。

Windows 本机全量回归 109 项，107 项通过、2 项符号链接权限限制跳过；包含真实鼠标勾选、直接添加、优先级统计、计时关闭与小窗口布局验证。跨平台最终结果见私有仓库对应提交的 CI。

## v0.7.0

产品重心调整为每天开始 Agent 工作的个人工作台。一级导航缩为今日、项目、Agent、资源库、数据安全、设置。

## 本次变化

- 今日成为默认首页。日程与可勾选任务保存每日 Markdown，Obsidian 外部编辑自动刷新；显示继续项目、最近进入和待处理异常。
- 项目保留既有规范，新增可自定义阶段、下一步概览、关联 Agent / 资源。八栏目阶段总结追加到 HANDOFF，提供可复制生成 Prompt 与人工编辑。
- Agent 统一常用入口、记录、目录、Markdown 备注与相关资源，Hermes 深度管理沿用原 Adapter。
- 资源库用统一 frontmatter 管理 Prompt、Skill、MCP、工具与资料，支持搜索、收藏、类型 / 项目 / Agent 筛选，正文与 Obsidian 共用。
- 备份恢复、校验、演练、换电脑、历史与必要诊断集中数据安全。隐藏重复旧工作笔记入口，原文件保留并可查阅。
- 文件读写有大小 / 路径限制与编辑冲突保护；读取在后台完成。进程检测仅保护概览按需运行。

## 兼容性

配置只增加 workbench_schema=1 和可选资料路径；不升级 .amb 格式、不重写 projects.json、不改变旧登记 id。旧项目缺少阶段字段仍能查看；保存新字段才修补 STATUS。原加密、迁移、便携路径与 Obsidian 项目联接继续使用。

资源库登记状态由用户填写，不能当成已执行安装 / 测试的证据。本版不连接 MCP，不自动调用 AI，不实现云盘、邮件、日历或自动协作平台。

## 验证

自动化测试覆盖原备份 / 恢复 / 加密 / 快照 / 迁移 / 便携 / 项目 / Obsidian，以及新增每日任务保存、外部刷新、资源创建搜索收藏、数据兼容和“今日 → 项目 → 总结 → 资源”GUI 链路。也覆盖旧阶段进展原文保护、关闭期间后台读取、未配置 Agent 和合法系统目录别名。

本机 Windows 运行 105 项测试：103 项通过，2 项因符号链接权限限制跳过。窗口响应测量约 0.71 秒构造与显示、14 秒运行期最长界面心跳间隔约 77 毫秒（11 项登记的独立副本，不包含打包运行时加载）。完整结果见 [验证记录](VALIDATION.md)。其他平台通过现有 CI 构建验证，不把本机结果表述为所有电脑实测。

macOS 原子保存的文件通知增加可见首页的轻量读取兜底；只读取今日文件，不周期性扫描项目。监听路径按差异更新，保留已存在的目录监听。
