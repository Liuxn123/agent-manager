# Agent 管家 v0.7.0

产品重心调整为每天开始 Agent 工作的个人工作台。一级导航缩为今日、项目、Agent、资源库、数据安全、设置。

## 本次变化

- 今日成为默认首页。日程与可勾选任务保存每日 Markdown，Obsidian 外部编辑自动刷新；显示继续项目、最近进入和待处理异常。
- 项目保留既有规范，新增可自定义阶段、下一步概览、关联 Agent / 资源。八栏目阶段总结追加到 HANDOFF，提供可复制生成 Prompt 与人工编辑。
- Agent 统一常用入口、记录、目录、Markdown 备注与相关资源，Hermes 深度管理沿用原 Adapter。
- 资源库用统一 frontmatter 管理 Prompt、Skill、MCP、工具与资料，支持搜索、收藏、类型 / 项目 / Agent 筛选，正文与 Obsidian 共用。
- 备份恢复、校验、演练、换电脑、历史与必要诊断集中数据安全。隐藏重复旧工作笔记入口，原文件保留并可查阅。
- 文件读写有大小 / 路径限制与编辑冲突保护；读取在后台完成。进程检测仅保护概览按需运行。

## 兼容性

配置只增加 workbench_schema=1 和可选资料路径；不升级 .amb 格式、不重写 projects.json、不改变旧登记 id。旧项目缺少阶段字段仍能查看；保存新字段才修补 STATUS。原加密、迁移、便携路径与 Obsidian 项目联接继续使用。

资源库登记状态由用户填写，不能当成已执行安装 / 测试的证据。本版不连接 MCP，不自动调用 AI，不实现云盘、邮件、日历或自动协作平台。

## 验证

自动化测试覆盖原备份 / 恢复 / 加密 / 快照 / 迁移 / 便携 / 项目 / Obsidian，以及新增每日任务保存、外部刷新、资源创建搜索收藏、数据兼容和“今日 → 项目 → 总结 → 资源”GUI 链路。也覆盖旧阶段长说明保存、关闭期间后台读取、未配置 Agent 和合法系统目录别名。

本机 Windows 运行 104 项测试：102 项通过，2 项因符号链接权限限制跳过。窗口响应测量约 0.78 秒构造与显示、14 秒运行期最长界面心跳间隔约 79 毫秒（11 项登记的独立副本，不包含打包运行时加载）。完整结果见 [验证记录](VALIDATION.md)。其他平台仍需现有 CI 构建验证，不把本机结果表述为所有电脑实测。
