# 路线图

## v0.1 初步实现

- [x] 独立 Qt 界面：四个主模块、设置、总览、备份与任务中心。
- [x] 跨平台路径、可配置工具和凭据引用。
- [x] 本地 Hermes 原生备份、校验、恢复预览与执行、共享备份锁。
- [x] 服务器连接、状态、网关控制、服务器侧备份/校验和空目录数据恢复。
- [x] 项目/Vault 加密备份、附件和工作文件、Git bundle、空目录还原。
- [x] Agent 登记、非交互进程启停、资料备份。
- [x] 系统凭据管理、配置迁移、后台任务与中断识别。
- [x] 多平台测试与构建工作流。

## v0.2 已实现

- [x] Hermes 为主，新增 Codex、WorkBuddy、CodeBuddy、Claude Code 和自定义 Agent 的本地资料登记。
- [x] 项目、记录、配置、附件及数据库多目录打包为一个加密备份文件。
- [x] 新电脑直接从备份文件恢复，选择目录后自动登记，无需先迁移管家配置。
- [x] 常见文本 / Markdown / JSON / JSONL 记录只读浏览；对话内容不写入任务日志。
- [x] 中文三步引导，并在真实 Windows 窗口完成模拟备份、恢复和记录阅读。

## 接下来优先

1. 实际服务器隔离演练，远端任务 ID / 状态文件 / 重连查询；生产写操作的完整回证。
2. 历史 Git 快照在隔离副本中选版本恢复，并重新绑定正式仓库路径。
3. 服务器 pinned runtime 与 systemd 安装流程；原地恢复、救援、可验证回滚和重复网关检测。
4. 本地恢复后运行库、记忆、凭据与索引的统一检查；救援材料浏览和回滚助手。
5. 自定义目录保留/排除规则、版本保留、已校验与已演练状态记录、加密备份侧车索引重建。

## v0.3 个人 Agent 工作台

- Hermes、Codex、Claude Code、其他 Agent 的引擎适配器与会话入口。
- skills、MCP、cron、Docker 与依赖环境管理。
- 本地进程检测和可靠的跨重启接管；引擎专用停机与一致性备份。
- 多机器资源映射、受控定时备份、磁盘/备份过期提醒。
- 知识库同步、Obsidian 文件差异与链接检查、Git 工作树恢复助手。
- 启动签名、安装器、升级和诊断导出。

统一任务中心、凭据引用、恢复预览已作为公共基础加入。下一阶段最需要的是**可恢复性演练与跨电脑迁移检查**，随后再增加自动化与引擎能力。
