# Agent 管家路线图

## v0.7.8 · 精简今日页

- 移除优先级和专注计时控件。
- 每日计划编辑后同步刷新今日任务与对应日期 Todo。

## v0.7.7 · 调整今日任务顺序

- 今日页先显示“今日要做”，再显示 Todo。

## v0.7.6 · 收简今日任务区

- Todo 可设截止日期，今日要做显示所选日期任务。
- 首页只保留两块任务清单，完整日程仍在日程总览查看。

## v0.7.5 · 归档与接续修复

- 解决 Windows 目录监听占用，归档 / 重新启用完成后恢复监听与项目选择。
- 失败保留步骤和底层原因，区分未移动与需要核对现场的中断。
- 旧归档通过新编号项目接续，沿用原规范，不搬动历史资料。

## v0.7.4 · 总体日程

- 首页默认今天，支持过去 / 未来日期选择、前后一天与回到今天。
- 二级“日程总览”统一查看未来 30 天、所有未完成任务、全部已登记事项及自选范围。
- 添加任务 / 日程可选日期；复用每日 Markdown 与 Obsidian，无外部日历平台。
- 按需后台索引与缓存，日期响应校验、原文冲突保护；不增加正文数据库或改备份格式。

## v0.7.3 · 日常入口修复

- 解决启动数据位置不一致导致的空项目，完善首次使用引导。
- 验证新建、资源关联、备注保存、缺失文档和按钮反馈。
- 优先修复日常操作闭环，维持原备份与恢复安全边界。

## v0.7.2 · 项目工作区优化

- 左侧项目卡片、右侧当前阶段与下一步，常用操作就近展示。
- 目标、进展、阶段总结、行动、风险与最近记录采用自适应卡片；保留完整原文。
- 从既有 TASKS / HANDOFF 读取真实统计，任务入口文件不推算完成率。
- 合并目录、归档和 Obsidian 索引操作；不改项目规范、SQLite、备份格式与迁移机制。

## v0.7.1 · 今日体验优化

- 根据实际试用简化首页：真实统计、今日重点、任务与时间轴、项目卡片和紧凑保护状态。
- 直接添加任务 / 日程，仍共用 Markdown；手动专注计时，不采集 Agent 活动。
- 小窗口保留任务与项目双栏，减少装饰；不引入天气服务或额外同步平台。

## v0.7.0 · 每天开始工作的个人工作台

- 默认今日：Markdown 日程 / 勾选任务、继续项目、最近使用、需要处理事项、必要备份状态。
- 项目复用 STATUS / TASKS / HANDOFF 与 Obsidian，突出阶段、下一步；自定义阶段、阶段总结与关联 Agent / 资源。
- Agent 统一日常入口、记录、目录、备注与关联资源，原登记与 Adapter 保留。
- 单一资源库登记 Prompt / Skill / MCP / 工具 / 网站 / GitHub / 文章 / 模板等，搜索、类型 / 收藏筛选、Markdown 与 frontmatter。
- 原备份、加密、校验、演练、迁移、便携和诊断集中数据安全。
- 增量配置迁移，不改旧项目注册表或备份格式；防覆盖外部编辑。

验收以“打开今日 → 进入项目 → 找 Agent 与资源 → 继续工作”为主，功能数量不是目标。

## 下一轮以真实使用决定

优先收集：今日计划是否每天会写、项目下一步是否清晰、哪些收藏经常找不到、哪些异常提示能促成处理。

可能的小改进：今日任务更方便的单项输入、选择已有 Markdown 目录的引导、关联资源的常用筛选、阶段总结 Prompt 的个人模板。先验证必要性，再实施；保留 Markdown 真源与兼容性。

如果已有安全 Agent 调用接口可复用，再考虑人工触发生成阶段总结；不为此引入复杂 AI 框架。

## 暂不实施

完整日历或 Google Calendar、Gmail / 云盘客户端、完整 MCP Host / Client、工作流引擎、多 Agent 自动编排、复杂 AI 调度、桌面 / 浏览器自动化、完整知识库 / 项目管理 / 笔记软件、替代 Obsidian。

## 必须持续保护

Hermes 原生备份 / 恢复、.amb schema 1 与解密兼容、错误密码与篡改拒绝、恢复目标防覆盖、恢复演练、凭据边界、SQLite 与聊天快照、项目编号和归档生命周期、Obsidian 真文件、U 盘路径。新增日常能力不能削弱这些保障。
